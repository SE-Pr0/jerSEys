# Frontend

This is the Vite app used for Vercel deployment.

Common commands:

- `npm install`
- `npm run dev`
- `npm run build`

Deploy this folder to Vercel and keep `backend/` out of the Vercel project.

Set `VITE_API_URL` in Vercel to the public backend URL ending in `/api`. Copy `.env.example` for local development; do not commit `.env` files.
